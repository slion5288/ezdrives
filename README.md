# EZDRIVES — 汽车教练预约系统

现代化、双语（English / 简体中文）的加拿大汽车教练课程预约网站。
由 **8 个 AI Agent 分工协作**完成：架构拆解 → UI 设计 → 核心数据层 → 四个并行编码 Agent（组件库 / 落地页 / 学生端 / 教练端）→ 集成验证。

## 快速开始

**线上地址（Cloudflare Pages + 自定义域名）**：
- https://ezdrives.net （正式域名）
- https://ezdrives.pages.dev （Pages 默认地址）

**自动化部署（GitHub → Cloudflare）**：代码推送到 `main` 分支后，GitHub Actions
（`.github/workflows/deploy.yml`）自动构建并部署到 Cloudflare Pages，无需手动操作。
仓库：https://github.com/slion5288/ezdrives

**方式一：无需终端，直接双击预览**
双击项目根目录的 **`Preview.html`**，即可在浏览器中打开完整网站（中英文切换、明暗主题、学生/教练端全部可用；纯前端演示，无需服务器/网络）。改动代码后执行 `npm run make:preview` 可重新生成。

**方式二：终端运行**

```bash
npm install
npm run dev        # 开发服务器 → http://localhost:5173
npm run build      # 生产构建（tsc --noEmit && vite build）→ dist/
npm run preview    # 预览生产构建
npm run make:preview  # 重新生成单文件 Preview.html（自动先构建）
npm run deploy     # 本地直接部署到 Cloudflare Pages（需先 npx wrangler login）
```

> 部署与域名绑定详见 `docs/DEPLOY.md`；线上为 `dist/` 静态产物（HashRouter，含 `_redirects` SPA 回退与资源缓存策略）。

## 数据存储（真实数据库）

**线上数据存储在 Cloudflare D1（SQLite 真实数据库）**，通过 Pages Functions
（`functions/` 目录）提供 REST API：

- **认证**：手机号 + 密码（PBKDF2 哈希），真实注册/登录/会话（`users`、`sessions` 表）
- **业务数据**：课程、车辆、视频、学员、预约、支付、通知均落库（按实体建表）
- **权限**：学生只能读写自己的预约/支付/通知；教练管理全局数据并确认收款
- **服务端校验**：购买门槛、时间冲突（含课间休息）、营业时间、数据归属
- 数据库结构见 `migrations/0001_init.sql`；前端通过 `src/data/api.ts` 调用

**教练账号**（单人部署，登录页「教练工作台」入口）：
- 手机号或邮箱登录；密码不在公开文档中列出（请向管理员索取或自行重置）

**学员账号**：在「课程预约」购买课程时用真实手机号注册（短信验证码由 Twilio Verify 发送）。

> 如果 `npm install` 报 `~/.npm` 权限错误，执行 `sudo chown -R 501:20 ~/.npm` 或设置 `npm_config_cache=/tmp/npm-cache` 后重试。

## 接入真实支付 API（Stripe / PayPal）

当前 Stripe/PayPal 尚未配置密钥（界面不显示测试提示）。要接入真实支付：

1. **Stripe（信用卡/储蓄卡/Apple Pay/Google Pay）**：
   - 注册 stripe.com 获取 Publishable Key（如 `pk_live_…`）
   - 部署一个后端接口创建 PaymentIntent（**Secret Key 只能放服务器**）
   - 在 `src/data/paymentGateway.ts` 的 `PAYMENT_GATEWAY_CONFIG` 填入 `stripePublishableKey` 与 `stripeCreateIntentUrl`，前端卡片表单将自动走 Stripe 安全支付（3DS 验证等）
2. **PayPal**：在 developer.paypal.com 注册应用获取 Client ID；在配置中填入 `paypalClientId` 与后端 `paypalCreateOrderUrl`（orders create/capture）
3. **Interac e-Transfer / 微信个人收款码**：个人账号无公开扣款 API，采用真实流程——学员转账/扫码后填写参考号，教练核对到账后点击确认
4. 所有支付仍遵循：提交 → 待教练确认 → 教练核对收款 → 确认后解锁预约（系统自动通知双方）

## 功能总览

- **G1 模拟题库**：主页「G1 模拟题库」栏目 → `/g1`，完整收录 ccdriving.ca 两套题库（中文 205 题 + 英文 188 题，144 张图离线内嵌）；选答即时显示对错，**结束后显示对错统计 + 错题回顾列表**（每题标出你的答案与正确答案），通过线 80%。
- **首页教学视频（最新）**：教练在「设置」页添加/编辑/删除教学视频——支持 **YouTube 链接**（自动提取 ID）或**上传本地视频**（无固定大小限制，仅受浏览器存储空间约束，超限时给出明确提示）；可排序、上下架。**播放体验**：首页与教练端均以封面卡片展示，**点击后在应用窗口内直接播放**（YouTube 走内嵌播放器、本地视频走原生播放器，绝不跳转到 YouTube）。**嵌入限制降级**：若视频作者禁止嵌入（YouTube 错误 150/153），播放前通过 oEmbed 预检识别，显示明确提示 + 「在 YouTube 打开」按钮，而不是报错。
- **课程与价格（最新）**：首页课程栏目改为**横向滚动展示全部上架课程**（桌面端），移动端显示前 3 个课程 + 「查看更多课程」入口 → 新增公开页 `/courses`（全课程网格 + G1 入口）。
- **教练设置页（最新）**：原「车辆管理」页升级为「**设置**」页，集中管理四类配置——①**车辆管理**（车辆增删改、照片、上下架）；②**教学视频**（YouTube/本地短视频的增删改与排序）；③**支付方式**（8 种支付方式的启用开关，学员支付弹窗**实时跟随**该列表，至少保留一种）；④**收款设置**（微信收款码、Interac e-Transfer 邮箱、银行账户、Stripe/PayPal 凭证）。原「支付确认」页只保留待确认支付的处理。
- **支付设置 ↔ 学员端映射（最新）**：教练在「设置」页启用的支付方式会**即时同步到学员端支付弹窗**（只显示已启用方式）；学员选微信支付时展示收款码、选 e-Transfer 时展示收款邮箱、选现金/转账时展示银行账户信息（银行名、户名、Transit/Institution/Account）；Stripe/PayPal 凭证配置后卡片/PayPal 走真实 API，否则演示模式。
- **预约引擎（最新）**：课时按**整点小时**为单位（1 小时 / 2 小时课程）；教练可设置**课间休息时间**（0–30 分钟）——**同一学员连续两节课无需休息**，其他学员预约从休息时间之后开始（可能产生非整点开始时间，如 14:10）；教练日程只显示已预约色块（隐藏可约色块），色块内直接显示**学员姓名、电话、接送地址**。
- **课程套餐（最新）**：课程分「**单小时**」与「**套餐（10 课时）**」；套餐每课时可独立编辑名称/内容/价格；学生预约套餐时**选择课时并连约 1–N 个课时**、在日历选开始时间，预约记录显示「第 X 课时」，**已完成课时自动打勾**，进度（已完成/10）实时显示。
- **学员管理（最新）**：教练后台新增学员统计页，以表格列出所有学员的姓名、电话、接送地址、邮箱、所上课程（含课时）、课时数与消费金额。
- **登录/注册（最新）**：主页底部「快速链接」仅保留「教练工作台」入口（学员登录通过课程购买流程进入）；教练端为**手机号/邮箱 + 密码**直接登录（单人部署，无短信验证）；学员注册需**姓名 + 手机号短信验证码**，**接送地址**在登录后于个人中心填写。
- **学生端**：绿色可预约时段日历 → 选课程 → 确认预约；冲突提示「该时段已被预约」；个人中心（预约/取消/历史时间轴）；真实 ICS 日历导出 + 订阅链接；通知中心（预约确认/取消/改期/2 小时提醒）。
- **教练端**：顶部导航（logo 左上方，点击返回首页；菜单居中）；周常规工作时间 + 临时关闭/改期（30 分钟粒度，保存后自动取消冲突预约并通知学员）；日程周历（改期/取消/批量移动/CSV 导出）；统计面板（本月课时、收入、新学员、课程分布环图、预约趋势折线、高峰柱状图）；课程与车辆管理（双语、CAD 价格、车辆照片上传）；**设置页**统一管理车辆/视频/支付方式/收款设置。
- **通用**：中英文一键切换（564 键 × 2，键集完全一致）、明暗双主题、全站响应式、**Cloudflare D1 真实数据库**（注册登录 + 业务数据落库，多设备共享、双向 30 秒同步）。
- **设计规范（最新）**：全站品牌统一为 **EZDRIVES**（蓝→紫渐变，Logo 在落地页/学生端/教练端三处一致）；落地页 hero 增加品牌氛围光晕；移动端底部导航升级为**悬浮毛玻璃胶囊**（blur + 圆角 + 安全区适配）；文案与当前产品逻辑对齐（整点课时、课间休息、空闲时段，无过时"绿色时段/30 分钟"表述）。
